# The Magic Candle II — reverse engineering project

Goal: fully document the game's rules/data formats, with an eye to a faithful port (web/TS/WASM or native).

## Layout
- `original/` — pristine, read-only copy of the installed game directory (v2.00 patch, see below). Never edit; copy elsewhere to experiment. Run the game in DOSBox or a Boxer gamebox.
- `tools/` — analysis scripts. Python via `.venv/bin/python -I` (python-idb installed).
- `docs/` — findings: file formats, game rules, decisions, handoffs.

## What we know (verified 2026-10-27)
- Version 2.00 "VGA only, mouse" patch (see `original/Readver2.txt`, `README.TXT`). Publisher Mindcraft, 1991.
- `MC2.EXE` 323,931 bytes, 16-bit real-mode DOS MZ, **Borland C++ 1991**. Uses Creative CTVDSK driver (VOC playback).
  `MC2BLAH.EXE` = same file with 3 bytes changed ("uit"→"UIT" at 0x197C7); ignore.
- Code is split: EXE + 25 `*.MCO` **code overlays** (`P90.MCO` starts with a jmp table, `FFFAR.MCO` starts with `push bp; mov bp,sp`). Any disassembly must load overlays too.
- `MC2.idb` (IDA 6-era, June 2013) is auto-analysis only: 645 funcs, 0 user names/comments. No value; gitignored.
- **`MC2.EXE` contains full Borland TDInfo debug symbols** (v3.16, appended after the load module): 29 modules, ~1000 named functions, ~2000 data labels, 246 typedef'd structs with member names. `tools/tdinfo.py` parses it; `tools/tdinfo_export.py` writes `docs/symbols.txt`, `docs/structs.h`, `ghidra/symbols.tsv`. Overlays (`*.MCO`) have no symbols.
- Ghidra project: `ghidra/MC2.gpr` (gitignored, regenerate: import `original/MC2.EXE` with `x86:LE:16:Real Mode`, then run `ghidra/scripts/ApplyTdinfo.java ghidra/symbols.tsv` headless). TDInfo segment + 0x1000 = Ghidra segment.
- Data formats: see `docs/formats.md` (single source of truth). Status 2026-10-27: VGA/EGA tilesets **done**; map blocks **150/170 render**; locations (`D` files) compose blocks into full maps (`tools/loc.py original out/locs`) — world map + all towns/dungeons render (`.venv/bin/python -I tools/render_all.py original out/maps`); open: `E80` maps have no tileset, `GnnE00.MCM` = 11×9 room interiors and arenas (`docs/formats.md`, *Room maps*).
- Render anything to check a hypothesis: `tools/render.py tileset|map ...`. Guess a grid width with `tools/rowwidth.py FILE:offset`.

- Overlays (`P*.MCO`): mechanism in `docs/overlays.md`, API table `docs/overlay_api.md`, roles `docs/overlay_index.md`. Readable decompiles committed under `decomp/overlays/` (regenerate with `tools/ovl_batch.sh` + `tools/ovl_pp.py`). Full EXE decompile: run `DecompileAll.java` (10 MB, kept in `out/`, not committed).

- Game rules: `docs/rules/*.md` (combat, spells, time_weather, npcs, items, economy, dialogue, camp, locations, skills, assignments, services, special_rooms, quest_scenes, encounters, ships, new_game), each citing the decompiled source. FFFAR INT 62h dispatch: `ghidra/fffar_dispatch.json`, `ghidra/int62.json`; combat INT 61h = `V06.MCO`: `ghidra/int61_v06.json`, `decomp/overlays/V06.c`; town INT 60h = `V02.MCO` (`ghidra/int60_v02.json`, `decomp/overlays/V02.c`, Ghidra base 3100), `V05.MCO` (3200). `tools/vdispatch.py` maps a V-module's AH services.
- Saves `FFSAVx.MCS` = raw DS image from 0x4CF6 (`_startsvdta`); parse globals straight from them. Location sub-tables: `tools/locdump.py original out/locs` (per-location NPC/room/text dump + `npcs.txt`). Conversation files `Cnn.MCV` (NPC n → C(n>>3) slot n&7): `tools/convdump.py original` (trade skill, shop prices, gift quests); `tools/talkdump.py original out/talk` (every keyword → response tree, P91 script format); `tools/events.py original decomp/overlays > docs/events.md` (event-bit cross-reference); `tools/doors.py original` (every town door → overlay, room D-file, room id; `pgmnum` n = `P0n.MCO`; dungeon levels are program 2 like towns, and a door with `pgmnum` 6 is a guarded dungeon room: fight first (`_DoACmbt` loads P06 = combat room program at 0CA8:2000), then P07).
- Gotchas: `ROOM.pgm` is an index into the location's PGM list, not an overlay number; room D-files (D05–D14, D19, D59, D61, D74…) are not towns, `locdump` mis-parses their room/pgm rows but their `loctext` is right; D-files whose first word is < 0x1F are banks of LOCTYPE records (houses, `docs/formats.md`). Room interiors are `G` file chunks: `tools/render_rooms.py original out/rooms` then `tools/gallery.py out` → `out/index.html` (with `tools/loc.py original out/locs`). `OV_0xNNN` in decompiles = file offset NNN−0x100 (DI = load offset − 0x100). FFFAR runs 4 bytes above its file image: an absolute `cs:[0xNNNN]` in `FFFAR.c` is file offset NNNN−4 (verified on its string table). Ghidra's decompile drops register-passed args in overlay code; read the asm with `tools/dis.py` for formulas. `echo ====` breaks in zsh (`=word` expansion). ROOM (door) lists end at the first record with `x == 0`, not at the next table pointer. `R90.MCV` is not a region: it is the 31 companion `HERO` records (= FFSAVA `_member6`). Party squares: member = origin + (cell mod 3, cell div 3), origin = window + (4,3) in town or the P05 room base; the leader is in cell 0 (check positions against a save's `_p1x/_p1y`, DS:4D2E/4D34). Common-text ("comtxt") message *n* = the n-th NUL-terminated string at EXE DS:0x9F8 (file 0x1800+0x15B50+0x9F8), counting from 0.

## Web port
- Decisions in `docs/decisions.md` (numbered; cite them in commits, e.g. `(decision 1)`). The engine reads a converted **data pack** (JSON + PNG) built locally by `tools/export_json.py` into `out/`; never commit or publish it. An in-browser TS converter comes before any public launch (decision 1). TS + Vite in `web/`, GitHub Pages (decision 3). Milestone 1: walk around Telermain (decision 2). Run: build the pack (`.venv/bin/python -I tools/export_json.py original out/pack`), then `cd web && npm install && npm run dev` (Vite serves `../out/pack` at `/pack/` in dev only). Check it headlessly: `node web/scripts/shot.mjs http://localhost:5173/ out.png ArrowLeft x5 …` (presses keys, types, clicks buttons by label; prints the status line and the open panel, saves a screenshot; the Chrome extension is not needed). Keys: arrows/WASD move, L look, T talk, U use, H whisper, M magic, C camp, I sheet, G game panel (save/load, decision 4). The game opens with the new-game screens (P81: Continue a saved slot, profile A–E, names, intro); any dev URL aid skips them (`?profile=0-4` picks the hero). Dev URL aids: `?level=Dnn` start level (with `?at=`), `?at=x,y` start square (stand south of a door and press ArrowUp), `?world=x,y` start on the world map (e.g. `24,40` is just south of a mushroom patch), `?hour=20`. `click:` only hits visible buttons (hidden panels keep stale ones); `eval:EXPR` prints a page expression (`dbg` = {party, world, clock, events, assigns, dunrms, level}; `dbg.dunrms.add('D34:248')` marks a guarded dungeon room's fight as won, so stepping through its door enters the room; in a fight also `dbg.fight`, the `Fight` (after the step that starts a fight add `wait:1500` before reading it); a second member for a test: `dbg.party.add(structuredClone(rec), hero.items, 3, x, y)` with a new `h_orinum`; e.g. `dbg.world.ships` to force ship states). Build multi-step shot arguments in a bash array (`args+=(…)`, `"${args[@]}"`): an unquoted string variable splits `eval:` expressions on spaces. A monster phase takes 200 ms per action, so wait several seconds after Pass before reading state. While a prompt asks to mark a square (Look, Teleport…), a click on the map marks it and Escape cancels. To click a map square (Look at a distance), dispatch a click on the canvas from `eval:`: it is 21×15 cells with the view centre (room square (5,4), or the leader) at column 10, row 7. In `format()` (talk.ts) `%o` is the `other` argument, never a `vars` entry. To force a patrol fight, move a patrol of the party's own region next to it (`dbg.world.ptrl[n]`, region = n >> 3; region 0 has none) and `dbg.world.engaged.add(n)`; a region whose `lastgen + interval` equals the month respawns on the first patrol move and undoes the edit. Camp (C): the commands only set activities, Begin runs the loop. Draw and Sheathe outside a fight are on the sheet (I); Talk is refused while the speaker holds a weapon (unless disguised). The ending: the Oolau bird room is the world spot `?world=62,20` + ArrowUp (wait:800 before editing the party there); Offer (P90 Give) is in conversations. The orc towns' Disguise gate: `?world=91,61` then ArrowUp (Glusaga); give the hero copies with `h_spells[4][1]`. Assign: I, a companion's sheet, *Assign*; Recall: Use the Mindstone (the player only); `dbg.assigns` holds the records (`dbg.assigns.daily({date, hour}, …)` runs a day by hand). World-map spots (strongholds, schools, huts, teleportals) are entered like features. Library books are not in the D-file: they are V05.MCO strings (`rules/services.md`, Library).

## Tooling plan
- Ghidra 12.2 installed via `brew install ghidra` (formula, not cask): `ghidraRun`; headless via `analyzeHeadless` (under Ghidra's `support/`). No IDA.
- DOSBox/Boxer for runtime; DOSBox-X if we need a debugger.
- Python scripts in `tools/` for data-format parsing; validate every format guess by rendering/round-tripping real files.
