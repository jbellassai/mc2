# Overlay → EXE call vector table

Overlay code (`*.MCO`, loaded at 1CA8:0000) reaches the EXE through a table of far pointers at `DS:25E6` (`_BSSstart`, DS = seg 15B5). Each overlay function prolog loads `BX` with that address from interrupt vector 3Fh, loads `SI = [BX]` (= 0x4CF6, the BSS start offset: overlay globals are addressed as `[SI+disp]`) and `DI = IVT[3E] + 0x1F00` (overlay-private data in `CS:[DI+n]`). Calls are `CALLF [BX+slot]`; slot 0 is the SI word, functions start at slot 4. `ghidra/vectors.json` is the machine-readable form; `tools/ovl_pp.py` applies it to decompiled overlay code.
