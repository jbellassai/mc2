# Open questions (player questions to answer from the code)

Status key: **answered** (with evidence), **partial**, **open**.

1. **Pearl plate vs Methreal armor** — answered (`docs/rules/items.md`). Armour is a flat per-hit damage reduction summed over worn pieces; the value table is in `D06.MCV` (ptr 9): Pearl plate **10**, Methreal **15** (Steel plate 8, helmets 1/2/4). No race/strength restriction is applied by the combat code; whether the wear menu restricts is TODO.
2. **Why magic skill never tops out** — answered (combat.md, *Skill advancement*). Caps come from `_maxtbl`: magic cap is 99 for a Wizard, 75 for Human and Elf, 0 for Halfling/Dwarf/Orc. The per-success improvement chance is `base + (50−skill)/4` below 50 and `base − (skill−50)/2` above, floored at 1 %, so a Wizard keeps creeping toward 99 and never visibly stops. TODO: confirm the base chance table and check camp *learn* (P93) uses the same cap.
3. **Clothing vs weather formula** — answered (`docs/rules/time_weather.md`). Per world-map step each member loses `terrain_energy[terrain] + max(0, clothing[outfit][weather] − tailor bonus)` energy; the 7×12 outfit table is in `P01.MCO` @0x2A2. Weather also adds up to 4 extra 5-minute ticks per step. `_tempert` is never used.
4. **Is Elvenspun clothing worth it** — answered: yes. Elvenspun costs at most 2 energy/step in any weather and is ≤ every other outfit in every weather (Furs cost 9 in Sweltering, Cotton/Silk 7–9 in Blizzard/Freezing).
5. **Rescuing party members who go missing** — partial (`docs/rules/npcs.md`). A companion who leaves (attitude 0xFF → `P97` dismissal) has their `_npcsta` bit cleared and reappears wherever the location tables (KNPC/RESID rows with their number, hours permitting) or an assignment record put them; none is deleted. Captive companions (KNPC type 0x1D) need `_capsta == 3`. Attitude 0xFF is set by the hireling payday check (`P92 ovl_09ff`: paid less than a fair share → leaves at 18:00, warning at 17:00) and volunteers leave after a combat once attitude ≤ 40 (`P95 ovl_0fc0`); see `docs/rules/economy.md` and `npcs.md`. Both only free the slot — the companion is back at their home location afterwards. Companions sent away with *Assign* live in `_assgn0` and can be **captured** while travelling (stealth check) and jailed in Dorak 1 / Maratul 2 / Ruz 1 / Maratul 8 / Shann 1 — `docs/rules/assignments.md`; *Recall* with a Mindstone reports where they are. Still TODO: P0x events that move companions.

7. **What is rope used for** — partial. The generic item handler (`FFRE` module, label `USEROPE` 0c2f:074E) is the shared "nothing happens" path with shovel, pick, horn, orb, scrolls, …: these items only act inside a location program that checks for them. Verified: `_UseItem` → FFFAR `ovl_173e` only shows the rope's picture, no overlay compares item code 0x47 (the `mov ax,0x47` hits are `_LoadMap(…)` calls), and no conversation text mentions rope. The EXE's use-item vector table (`UVECTBL`, FFRE 0c2f:0521) sends Rope, Shovel, Pick, Orb, Horn, Conch, Map, Map Flask, Fireglobe, Cylinder/Cone/Cube/Sphere/Pyramid and all scrolls to one shared handler that only prints "%o uses a %l." and reports failure ("can't use now"). The only place item 0x47 appears in data is `P08`'s exchange list (Conch, Rope, Blanket, Ishban, Demaro, Coin, …): when a quest NPC hands you an item there, the first of those you carry is taken in exchange. **Rope has no gameplay effect**; it is 35-value trade fodder (shops pay 40–60).
